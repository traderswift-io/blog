# TraderSwift blog

The guides and build notes of TraderSwift, the infrastructure layer for agentic trading. The site is built from plain Markdown into static HTML.

## How do I build it?

```
python3 build.py
```

The pages land in `dist/`. How to write a guide is in [CONVENTIONS.md](CONVENTIONS.md).
