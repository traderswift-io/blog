How did the old set leave?

Removing the old set, and revoking the old key.

TraderSwift update1 min readRead Markdown ↗

The old set left in three steps, once the new key had traded.

  1. The owner removed the old validators. In a second signed step, the old machines were taken out of the chain's validator set. From then on, only the new four could sign.
  2. The old signer machines were destroyed, on the owner's word. The fourth old machine, which only ran the chain, was wiped.
  3. The old key's policy was revoked on chain. With its policy revoked and its shares gone with the old machines, Signer can no longer sign with it.

Signing moved from the old key to the new one with no stop. There was no gap in which an order could not be signed.

The result is four validators, any three of which can sign.
