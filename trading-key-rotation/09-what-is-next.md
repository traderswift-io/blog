title: What is next?
description: The next rotation, new order limits, and more signers.
order: 9
---

The next rotation is built and tested. It waits on one signing moment, with no date set.

- **Updates, with the rotation.** Because the new machines are sealed, updates made after the seal can't be copied onto them. The next set is planned with a way to take a release the chain itself has approved.
- **Policy v2, after the rotation, no date set.** A price band, so no order strays too far from the exchange's reference price, checked by each signer on its own price feed. And a cap on how many orders a key can sign per second; it is **Built, not live**.
- **Signers run by other operators.** Anyone can already join as a validator. Signers run by other operators need a later rotation, which is not yet scheduled.
