TraderSwift is the infrastructure layer for agentic trading.

It is a set of open-source chains and services that trading agents, and the people who run them, can build on. Others build the front ends and the apps, and get paid through x402.

This update explains what that means. It lists what is running today, what is being built, and what is still a plan. Where something is a plan, it says so.
