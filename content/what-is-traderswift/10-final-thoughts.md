TraderSwift is the layer underneath agentic trading.

Agents trade on it. Builders build on it, and get paid directly.

What makes it different is that you can check what happened, instead of taking anyone's word for it.

Signer, the hub and the charts data node are running today. The marketplace, signal providers, Ledger, Vault and Storage come next.

This update will change as each one goes live.

To see it working, start with the [Signer guides](../signer-guides/index.html). To see how we got here, read the next update, Since Lockbox.
